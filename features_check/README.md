# 角色属性录入工具

本地单人使用的 Python + Flask 网页工具。只维护 CSV 最新内容，不使用数据库、不保存历史或复核状态。运行需要 Python 3.10 或更新版本。

## 启动

在项目根目录执行：

```powershell
python -m pip install -r features_check/requirements.txt
python features_check/app.py "D:\path\characters.csv" --column hair_color
```

浏览器打开 http://127.0.0.1:5000 。终端按 Ctrl+C 退出。

CSV 必须有 `img_url`、`name_cn`、`subject_name_cn` 三列。页面展示图片、角色中文名、所属动漫中文名，不展示角色 ID。相对文件路径以启动命令所在目录为基准。

目标属性列不存在时，启动过程会自动新增空列并写入 CSV；存在时加载已有值。每次“保存并下一位”直接覆盖指定 CSV，请选择你希望编辑的文件。

## 选项与操作

- `hair_color`、`eye_color`、`hair_style` 提供中文快捷选项。快捷选项只填入文本框；点击保存才写入。属性值按输入原样保存，留空保存可清除属性。
- 任意自定义字段都支持文本录入，也可自定义快捷选项：

```powershell
python features_check/app.py "D:\path\characters.csv" --column hair_color --options black brown blonde silver unknown
```

- “全部角色 / 属性有值 / 属性为空”针对当前字段筛选。仅空字符串或全空白视为空，`NA`、`unknown` 等普通文本不视为空。
- 原始序号从 1 开始，不包括表头；同时展示筛选内位置。跳转目标不在当前筛选时自动切回全部角色。
- 上一位和跳过不写文件；存在未保存修改时询问是否放弃。文本框内按 Enter 保存并下一位。
- 保存后优先前往筛选队列中的下一位；当前记录退出筛选且后方无记录时回到筛选首位；没有匹配角色时显示空列表。
- 图片仅接受 HTTP/HTTPS URL，可点击打开原图，失败时可重试。预加载接下来两张图片，不批量下载。部分图片站可能限制外链或需要登录，加载失败时可以跳过。
- 不记录断点和历史，重启从第一位开始；用空值筛选继续录入。

## 文件保存

CSV 全部按文本读取，保留行序、列序、前导零、`NA` 等文本。自动处理 UTF-8 和 UTF-8 BOM；其他编码可用 `--encoding gb18030` 等指定。不支持自动猜测所有编码。

程序识别常见分隔符并保留编码和换行风格，CSV 引号格式可能经标准序列化调整。表头重复、缺少必要列或行字段数不一致时拒绝启动。

每次保存先写同目录临时文件并落盘，再替换 CSV。失败时不更新内存值、不跳转，输入保留；成功后不保留临时文件。意外中断可能留下 `.features-check-*.tmp` 文件，原 CSV 核对正常后可删除。

保存前检查原文件摘要，发现外部修改会拒绝覆盖，需要重启重新加载。此检查不是跨程序文件锁，请勿同时用 Excel 或其他工具修改同一文件。Excel 占用文件导致保存失败时，关闭 Excel 后重试。多个浏览器标签页使用版本检查防止旧页面覆盖新结果。

默认端口 5000，可用 `--port 5001` 修改。服务仅绑定本机、关闭调试模式，适用于本地人工录入，不用于公开部署。

## 验证

```powershell
python -m unittest discover -s features_check -p "test_*.py" -v
```

测试使用临时 CSV，不修改真实数据，覆盖文本往返、列创建、保存失败、外部修改、多页面冲突及请求校验。
